# Протокол 2193

Neptune принимает протокол 2193 наряду с прежними версиями мультиверсии. Его используют Minecraft: Bedrock Edition 1.26.50 и 1.26.51.

Палитра блоков, творческий инвентарь и таблицы предметов хранятся отдельно в каталогах `2193`. Данные извлекаются из публичных выпусков Bedrock и не используются совместно с протоколами 2168 или 2169.
